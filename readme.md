# Coywolf SEO

> [!IMPORTANT]
> Coywolf SEO is no longer developed. Coywolf moved all of its sites from WordPress to [EmDash](https://emdashcms.com), and the plugin features it still uses are now in [Coywolf Pack for EmDash](https://github.com/coywolf-llc/coywolf-pack). The plugin is closed in the WordPress.org Plugin Directory. This repository is archived and read-only.

## Use Coywolf Pack instead

Coywolf SEO's features are now these modules in Coywolf Pack:

- [Redirects](https://github.com/coywolf-llc/coywolf-pack/blob/main/docs/redirects.md): external, file-path and regex redirects, imports, and automatic redirects for slug changes and removed content
- [Schema & Social](https://github.com/coywolf-llc/coywolf-pack/blob/main/docs/schema.md): one Schema.org graph per page, robots directives and Open Graph
- [Discovery](https://github.com/coywolf-llc/coywolf-pack/blob/main/docs/discovery.md): IndexNow, a news sitemap, and llms.txt with Markdown versions of entries
- [Robots.txt Rules](https://github.com/coywolf-llc/coywolf-pack/blob/main/docs/robots.md): plain-English robots.txt rules with a verified crawler directory
- [Link Manager](https://github.com/coywolf-llc/coywolf-pack/blob/main/docs/links.md): every link in your content with its status, and bulk replace, unlink and ignore
- [Headings & TOC](https://github.com/coywolf-llc/coywolf-pack/blob/main/docs/headings.md): linkable headings and a Table of Contents block
- [Breadcrumb Nav](https://github.com/coywolf-llc/coywolf-pack/blob/main/docs/breadcrumbs.md): an accessible breadcrumb trail
- [AI Enrichment](https://github.com/coywolf-llc/coywolf-pack/blob/main/docs/ai.md): Wikidata-grounded entities, meta descriptions and image alt text

To add Coywolf Pack to an EmDash site, follow its [Getting started](https://github.com/coywolf-llc/coywolf-pack#getting-started) guide.

## What this plugin did

An SEO plugin that had exactly what you need, and nothing more: titles and descriptions, schema, sitemaps, IndexNow, llms.txt, redirects, robots.txt rules, link management, breadcrumbs, a table of contents block and AI enrichment.

## If you still use it

The last release, [v1.1.12](https://github.com/coywolf-llc/coywolf-seo/releases/tag/v1.1.12), is still available, but it won't get updates, security fixes or support. The code stays here under the GPL-2.0-or-later license.
